# abac-system

> **Canonical source:** [FlorentinoG9/skills](https://github.com/FlorentinoG9/skills) (`skills/abac-system/`)

A skill for planning, implementing, verifying, and battle-testing production-grade, agnostic Attribute-Based Access Control (ABAC) systems.

**Author:** [FlorentinoG9](https://github.com/FlorentinoG9)

## Contents

- `SKILL.md` — skill activation contract, hard rules, decision gates, execution steps, and output contract
- `references/abac-requirements.md` — source requirements and eval scenarios

## Install

Preferred (from skills collection):

```bash
npx skills add FlorentinoG9/skills --skill abac-system
```

Or install this standalone repo directly:

### OpenCode (global)

```bash
git clone https://github.com/FlorentinoG9/abac-system-skill.git ~/.config/opencode/skills/abac-system
```

### Agents (global)

```bash
git clone https://github.com/FlorentinoG9/abac-system-skill.git ~/.agents/skills/abac-system
```

### Project-local

```bash
mkdir -p .opencode/skills
git clone https://github.com/FlorentinoG9/abac-system-skill.git .opencode/skills/abac-system
```
